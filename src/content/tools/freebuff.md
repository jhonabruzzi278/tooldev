## ¿Qué es?

Freebuff es un agente de programación gratuito que se financia con anuncios de texto en lugar de suscripciones. Ofrece una CLI para la terminal, un creador web en el navegador, workspaces cloud y chat de IA, todo sin pedir tarjeta ni API keys.

## ¿Para qué sirve?

Sirve para programar con ayuda de un agente de IA sin coste alguno: construir prototipos, corregir errores, aprender nuevas tecnologías y ejecutar tareas de código en la nube o en local.

## Cuándo usarla

- Cuando quieres un agente de código sin pagar suscripción ni configurar API keys.
- Para aprender, hacer side projects y prototipos con presupuesto cero.
- Si prefieres trabajar en la nube sin preparar un entorno local.

## Cuándo NO usarla

- Para proyectos empresariales con requisitos de privacidad y SLA estrictos.
- Si necesitas garantías de disponibilidad y soporte que un servicio gratuito con anuncios no ofrece.

## Pros

- Completamente gratis: sin suscripción, claves ni tarjeta.
- Múltiples entornos: terminal, navegador y workspaces cloud.
- Barrera de entrada mínima para principiantes.

## Contras

- El modelo financiado con anuncios puede no ser sostenible a largo plazo.
- Sin garantías empresariales de soporte o privacidad.
