## ¿Qué es?

tldraw es una pizarra de lienzo infinito rápida y minimalista, usable directamente desde el navegador sin registro. Además, ofrece un SDK de React para que los desarrolladores integren su motor de canvas en sus propias aplicaciones.

## ¿Para qué sirve?

Sirve para bocetar ideas, diagramas de arquitectura, wireframes y mapas visuales al instante, colaborar en tiempo real sin fricción y, para equipos de producto, construir experiencias de canvas personalizadas con su SDK.

## Cuándo usarla

- Cuando quieres dibujar algo ahora mismo sin crear cuentas.
- Para pizarras colaborativas ligeras con un simple enlace.
- Si desarrollas en React y necesitas un canvas editable en tu app.
- Para diagramas de arquitectura y wireframes rápidos de documentar.

## Cuándo NO usarla

- Si necesitas workshops con votaciones, temporizador y facilitación: Miro.
- Cuando buscas diseño de interfaces detallado con componentes: Penpot o Figma.
- Para producción comercial con el SDK sin revisar antes su licencia.

## Pros

- Cero fricción: abres la web y estás dibujando.
- Colaboración multijugador fluida y rápida.
- SDK de React potente para productos con canvas.
- Exportación a PNG, SVG y JSON sin complicaciones.

## Contras

- Menos funciones de facilitación que Miro o FigJam.
- La licencia del SDK para producción requiere revisión.
- Sin gestión avanzada de equipos y permisos empresariales.
