## ¿Qué es?

Fontshare es una colección de fuentes tipográficas profesionales y gratuitas creada por Indian Type Foundry. Todo su catálogo puede usarse en proyectos personales y comerciales sin pagar licencias ni crear cuentas.

## ¿Para qué sirve?

Sirve para dotar a webs, aplicaciones y marcas de tipografía de calidad profesional sin coste, con descarga directa de archivos y una API de CSS para incrustar las fuentes en proyectos web fácilmente.

## Cuándo usarla

- Cuando necesitas tipografía profesional sin presupuesto de licencias.
- Para proyectos comerciales que requieren licencia clara y gratuita.
- Si buscas alternativas con personalidad frente a Google Fonts.
- Cuando quieres descargar y autoalojar fuentes sin registrarte.

## Cuándo NO usarla

- Si necesitas una familia específica de una fundición de pago.
- Cuando el catálogo no cubre el estilo o idioma que buscas.
- Para sistemas tipográficos complejos con muchas variantes especiales.

## Pros

- Catálogo completo gratis incluso para uso comercial.
- Sin registro ni cuentas para descargar.
- Calidad profesional respaldada por una fundición real.
- API de CSS y variable fonts para la web.

## Contras

- Catálogo más pequeño que Google Fonts o fundiciones de pago.
- Menos variedad de escrituras no latinas.
- Sin herramientas de gestión de fuentes para equipos.
