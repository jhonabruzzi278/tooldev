## ¿Qué es?

Stitch es un experimento gratuito de Google Labs que genera diseños de interfaz a partir de prompts de texto, imágenes o wireframes. Además del diseño visual, produce código frontend y permite exportar el trabajo a Figma.

## ¿Para qué sirve?

Sirve para pasar rápidamente de una idea a una interfaz visual con código, acelerando la fase de prototipado de productos, landing pages y aplicaciones sin empezar desde un lienzo en blanco.

## Cuándo usarla

- Cuando quieres prototipar una UI en minutos a partir de una descripción o boceto.
- Para generar variantes de diseño que luego refinarás en Figma.
- Si necesitas código frontend inicial para validar una idea rápido.

## Cuándo NO usarla

- Para sistemas de diseño maduros donde la consistencia con tu librería de componentes es crítica.
- Como experimento de Labs, no es ideal depender de él para flujos de trabajo críticos a largo plazo.

## Pros

- Gratuito y sin curva de aprendizaje.
- Puente directo entre idea, diseño y código.
- Exportación a Figma muy útil para equipos de diseño.

## Contras

- Al ser experimental, sus funciones y límites pueden cambiar o desaparecer.
- El código generado requiere revisión y adaptación para producción.
